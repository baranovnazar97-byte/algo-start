# Шесть этапов публикации

Это запланированная поэтапная публикация уже подготовленного учебного проекта.
Этапы не предназначены для подделки дат или истории разработки.

Перед публикацией этап можно посмотреть локально:

```powershell
.\stage-1.cmd -Preview
npm run dev
```

После просмотра верните полную локальную версию командой:

```powershell
.\stage-6.cmd -Preview
```

## Неделя 1. Основа проекта

```powershell
.\stage-1.cmd
```

Публикуются главная страница, описание проекта, регистрация, вход, PostgreSQL,
личный кабинет и Docker. Игровых заданий пока нет.

## Неделя 2. Последовательности

```powershell
.\stage-2.cmd
```

Открывается игра «Шаг за шагом»: три уровня, проверка порядка действий,
начисление очков и сохранение результата в базе.

## Неделя 3. Команды роботу

```powershell
.\stage-3.cmd
```

В каталоге появляется «Робот-почтальон»: команды движения, препятствия и три
карты разной сложности. На сайте одновременно доступны две игры.

## Неделя 4. Поиск ошибок

```powershell
.\stage-4.cmd
```

Добавляется «Ловец ошибок» с тремя заданиями на анализ неправильного шага
алгоритма. На сайте доступны три игры.

## Неделя 5. Условия

```powershell
.\stage-5.cmd
```

Добавляется игра «Если - то». Каталог содержит все четыре игры и 12 уровней.

## Неделя 6. Финальная версия

```powershell
.\stage-6.cmd
```

Открываются страницы подробного прогресса и профиля, достижения, статистика и
финальный вариант навигации.

## Что делает каждая команда

Команда разрешает публиковать только следующий этап по порядку, затем:

1. меняет номер опубликованного этапа;
2. собирает frontend и backend;
3. запускает серверные тесты;
4. создаёт подписанный номером этапа Git-коммит;
5. отправляет его в `main` репозитория;
6. разворачивает этот же коммит на VPS;
7. только после успешного деплоя отмечает этап завершённым локально.

Состояние хранится в `.deploy/publication-state.json` и не попадает в GitHub.
Если GitHub или VPS временно недоступен, повторите ту же команду. Следующий этап
до успешного завершения текущего не запустится.
