# Документация проекта

- `Курсовой_проект_Алгоритмика.docx` — готовая пояснительная записка Word.
- `COURSE_PROJECT.md` — основной редактируемый текст.
- `USER_GUIDE.md` — руководство пользователя.
- `TEST_PLAN.md` — сценарии тестирования.
- `generate_docx.py` — генератор Word-файла.

Перед сдачей откройте DOCX и замените плейсхолдеры в квадратных скобках: образовательную организацию, дисциплину, город, группу, ФИО студентов и руководителя. Затем нажмите `Ctrl+A`, `F9`, чтобы Word обновил содержание и номера страниц.

После правок Markdown пересоберите файл:

```powershell
python -m pip install python-docx
python docs/generate_docx.py
```

Титульный лист и обязательная структура у разных учебных заведений отличаются. Сверьте оформление с методическими указаниями преподавателя.
