# АлгоСтарт — frontend

Клиентская часть учебного игрового тренажёра на React, TypeScript и Vite.

## Локальный запуск

```bash
npm install
npm run dev
```

Vite отправляет запросы `/api` на `http://localhost:3000`. Адрес можно изменить в `.env` через `VITE_DEV_API_TARGET`.

## Сборка

```bash
npm run build
```

Готовые файлы появятся в `dist/`.
